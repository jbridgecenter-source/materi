**Bab 3: Tempat & Lokasi (ここ・そこ・あそこ)**

Keterangan Tata Bahasa (文法)

**Keterangan warna:   Kata Benda**     **Kata Tunjuk**     **Partikel**     **Kata Kerja**     **Kata Sifat**     **です・ます (akhiran)**

| No | Tata Bahasa | Penjelasan | Contoh |
| --- | --- | --- | --- |
| 1 | ここ / そこ / あそこ (di sini, di situ, di sana)<br> ここ  /  そこ  /  あそこ | Penunjuk TEMPAT. ここ = di sini (dekat aku), そこ = di situ (dekat kamu), あそこ = di sana (jauh dari kita). Versi sopannya: こちら / そちら / あちら (juga bisa buat nunjuk arah). | トイレはあそこです。<br>toire wa asoko desu<br>→ Toiletnya di sana. |
| 2 | KB は (tempat) です (X ada di ...)<br> KB  +  は  +  tempat  +  です | Pola buat ngasih tahu posisi benda, tempat, atau orang: "X ada di [tempat]." | アンディさんはじむしょです。<br>Andi-san wa jimusho desu<br>→ Sdr. Andi ada di kantor. |
| 3 | どこ / どちら (di mana)<br> どこ  /  どちら | どこ = "di mana?". どちら lebih sopan, dan juga dipakai buat nanya negara, perusahaan, atau sekolah seseorang. | エレベーターはどこですか。<br>erebeetaa wa doko desu ka<br>→ Liftnya di mana? |
| 4 | KB₁ の KB₂ (buatan / asal)<br> KB₁  +  の  +  KB₂ | の di sini nunjukin ASAL atau BUATAN. Mis. にほんの くるま = mobil buatan Jepang. Buat nanya asal: どこの ～ですか. | これはにほんのくるまです。<br>kore wa Nihon no kuruma desu<br>→ Ini mobil buatan Jepang. |
| 5 | Keluarga こ・そ・あ・ど<br> こ～  /  そ～  /  あ～  /  ど～ | Trik mudah! こ = dekat aku, そ = dekat kamu, あ = jauh, ど = pertanyaan. Pola ini berlaku untuk benda (これ…), tempat (ここ…), dan arah/sopan (こちら…). Hafal satu, dapat semua! |   |
| 6 | お～ (awalan sopan)<br> お  +  KB | お di depan kata benda biar lebih sopan. Mis. くに → おくに, なまえ → おなまえ. | おくにはどちらですか。<br>okuni wa dochira desu ka<br>→ Anda berasal dari negara mana? |
