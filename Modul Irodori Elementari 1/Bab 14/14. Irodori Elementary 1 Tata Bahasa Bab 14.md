**Tata Bahasa Irodori Elementary 1 — Bab 14: 休みを取ってもいいでしょうか？**

Topik: 仕事の連絡 (Komunikasi dalam Pekerjaan)  •  Pola kalimat & contoh setia pada 文法ノート buku Irodori.

➊  Nで／ナA-で／イA-くて／V-て、～　＜penyebab / alasan＞

Fungsi: Menggabungkan dua kalimat di mana kalimat depan = ALASAN. N & ナA → ～で; イA → ～くて; verba → bentuk テ. Juga dipakai untuk meminta maaf dengan menyebut alasan.

**Contoh (dari buku):**

　道が混んでいて、ぜんぜん動きません。

　→ Jalanan macet sehingga sama sekali tidak bergerak.

　昨日は、休んですみませんでした。

　→ Maaf kemarin saya tidak masuk.

**Contoh tambahan (kosakata bab ini):**

　熱があって、会社を休みました。

　→ Saya tidak masuk kantor karena demam.

➋  S1。それで、S2

Fungsi: Menyatakan sebab–akibat antar kalimat dengan konjungsi 「それで」. S1 = alasan, S2 = akibat.

**Contoh (dari buku):**

　これから病院に行きます。それで、少し遅刻します。

　→ Saya akan ke rumah sakit sekarang. Karena itu, saya akan agak terlambat.

**Contoh tambahan (kosakata bab ini):**

　財布を忘れました。それで、家に帰ります。

　→ Dompet saya ketinggalan. Karena itu, saya pulang dulu.

➌  V-てもいいですか？

Fungsi: Meminta IZIN. Verba bentuk テ + もいいですか？. Jawaban mengizinkan: どうぞ／わかりました／いいです（よ）.

**Contoh (dari buku):**

　トイレに行って来てもいいですか？

　→ Bolehkah saya ke toilet sebentar?

**Contoh tambahan (kosakata bab ini):**

　ちょっと休憩してもいいですか？

　→ Bolehkah saya istirahat sebentar?

➍  V-てもいいでしょうか？

Fungsi: Meminta izin secara LEBIH SOPAN. 「～てもいいですか？」 → akhirannya jadi 「～でしょうか？」.

**Contoh (dari buku):**

　明日の午後、早退してもいいでしょうか？

　→ Apakah besok siang saya boleh pulang lebih awal?

**Contoh tambahan (kosakata bab ini):**

　来週の月曜日、休みを取ってもいいでしょうか？

　→ Apakah Senin depan saya boleh mengambil cuti?

➎  V-なければなりません

Fungsi: Menyatakan KEHARUSAN (terlepas dari keinginan). Verba bentuk ナイ → ～なければなりません. Bentuk biasa: ～なければならない. Untuk alasan sering + んです.

**Contoh (dari buku):**

　ちょっと、役所に行かなければならないんです。

　→ Saya harus pergi ke balai kota.

**Contoh tambahan (kosakata bab ini):**

　今日は家にいなければなりません。

　→ Hari ini saya harus berada di rumah.

➏  ～んです ①

Fungsi: Menjelaskan keadaan/alasan kepada lawan bicara (di sini: alasan minta cuti / pulang awal). Bentuk 「～んです」 tanpa 「が…」.

**Contoh (dari buku):**

　東京から、国の友だちが来るんです。

　→ Teman dari negara saya akan datang dari Tokyo.

**Contoh tambahan (kosakata bab ini):**

　市役所に行かなければならないんです。

　→ Saya harus pergi ke balai kota.
