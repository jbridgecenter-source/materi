**Tata Bahasa Irodori Elementary 1 — Bab 2: ゲームをするのが好きです**

Topik: 今の私 (Saya Saat Ini)  •  Pola kalimat & contoh setia pada 文法ノート buku Irodori.

➊  V-ることです

Fungsi: Menyatakan hobi dengan kata kerja. Verba bentuk kamus + こと mengubah verba menjadi kata benda (hobi). Untuk verba ～する bisa juga 「N＋することです」atau 「Nです」.

**Contoh (dari buku):**

　趣味は映画を見ることです。

　→ Hobi saya menonton film.

**Contoh tambahan (kosakata bab ini):**

　趣味は音楽を聞くことです。

　→ Hobi saya mendengarkan musik.

➋  V-るのが好きです

Fungsi: Menyatakan suka melakukan suatu kegiatan. Verba bentuk kamus + の (penominal) + が好きです. Bentuk negatif: ～のは好きじゃないです／ありません.

**Contoh (dari buku):**

　ゲームをするのが好きです。

　→ Saya suka main game.

**Contoh tambahan (kosakata bab ini):**

　私は写真を撮るのが好きです。

　→ Saya suka mengambil foto.

➌  【orang】と　【tempat】で　V-ます

Fungsi: Menyatakan DENGAN SIAPA dan DI MANA suatu kegiatan dilakukan. Partikel と = dengan (teman); で = tempat. Urutan penyebutan bebas.

**Contoh (dari buku):**

　休みの日は、たいてい友だちと体育館でバドミントンをします。

　→ Pada hari libur saya biasanya main bulu tangkis bersama teman di gedung olahraga.

**Contoh tambahan (kosakata bab ini):**

　日曜日に、家族と海でキャンプをします。

　→ Hari Minggu saya berkemah bersama keluarga di laut/pantai.

➍  V1-て、V2

Fungsi: Menyatakan dua kegiatan atau lebih secara berurutan, dihubungkan dengan verba bentuk テ. Dipakai untuk kebiasaan, peristiwa lampau, maupun rencana.

**Contoh (dari buku):**

　毎週、夕方までバドミントンをして、そのあと、みんなでご飯を食べます。

　→ Setiap minggu kami main bulu tangkis sampai sore, lalu makan bersama.

**Contoh tambahan (kosakata bab ini):**

　休みの日は、本を読んで、音楽を聞きます。

　→ Pada hari libur saya membaca buku lalu mendengarkan musik.

➎  V-ています ②

Fungsi: 「Verba bentuk テ + います」 di sini menyatakan kebiasaan / kegiatan yang dilakukan berulang dalam jangka waktu tertentu (mis. les yang sedang dijalani).

**Contoh (dari buku):**

　いけばなを習っています。

　→ Saya sedang belajar ikebana.

**Contoh tambahan (kosakata bab ini):**

　毎朝、ジョギングをしています。

　→ Saya joging setiap pagi.

➏  Nができます

Fungsi: Menyatakan kemampuan (bisa). Untuk bahasa memakai ～語. Selain bahasa, bisa untuk olahraga, alat musik, dll.

**Contoh (dari buku):**

　日本語、英語、フィリピノ語、スペイン語ができます。

　→ Saya bisa bahasa Jepang, Inggris, Filipina, dan Spanyol.

**Contoh tambahan (kosakata bab ini):**

　私はテニスができます。

　→ Saya bisa bermain tenis.
