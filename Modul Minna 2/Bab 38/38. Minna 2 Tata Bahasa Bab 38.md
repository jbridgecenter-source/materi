**Bab 38: Menominakan Kalimat dengan の (〜のは / 〜のが / 〜のを)**

Keterangan Tata Bahasa (文法)

**Keterangan warna:   Kata Benda**     **Kata Tunjuk**     **Partikel**     **Kata Kerja**     **Kata Sifat**     **です・ます (akhiran)**

| No | Tata Bahasa | Penjelasan | Contoh |
| --- | --- | --- | --- |
| 1 | KK Kamus の は + K.Sifat です (melakukan X itu ...)<br> KK Kamus  +  の は  +  K.Sifat です | の di sini "menyulap" kata kerja/kalimat jadi seperti kata benda (nominalisasi). Pola のは + kata sifat dipakai untuk menilai SUATU KEGIATAN ("melakukan ... itu menarik/sulit/menyenangkan"). Kata kerja sebelum の memakai Bentuk Kamus (bentuk biasa). | テニスをするのはおもしろいです。<br>tenisu o suru no wa omoshiroi desu<br>→ Bermain tenis itu menarik. |
| 2 | KK Kamus の が + K.Sifat です (suka/pandai melakukan X)<br> KK Kamus  +  の が  +  K.Sifat です | のが + kata sifat dipakai dengan sifat yang menyatakan SUKA/MAHIR/CEPAT, dll. (すき、きらい、じょうず、へた、はやい、おそい). Jadi: "suka/pandai/cepat melakukan ...". | わたしははなをそだてるのがすきです。<br>watashi wa hana o sodateru no ga suki desu<br>→ Saya suka memelihara bunga. |
| 3 | KK Kamus の を 忘れました (lupa melakukan X)<br> KK Kamus  +  の を  +  忘れました | Untuk bilang "lupa MELAKUKAN sesuatu" (bukan lupa benda), ubah kegiatannya jadi kata benda dengan の lalu tandai を + わすれました. | ぎゅうにゅうをかうのをわすれました。<br>gyuunyuu o kau no o wasuremashita<br>→ Saya lupa membeli susu. |
| 4 | [Bentuk Biasa] の を 知って いますか (tahu bahwa ...?)<br> Kalimat (Bentuk Biasa)  +  の を  +  知って いますか | Untuk menanyakan apakah seseorang TAHU tentang suatu fakta/kejadian. Isi yang ditanyakan diubah ke Bentuk Biasa + の. Jika baru tahu dari pertanyaan itu, jawab しりませんでした; jika memang tidak tahu sejak awal, jawab しりません. | ブディさんがけっこんするのをしって いますか。<br>Budi-san ga kekkon suru no o shitte imasu ka<br>→ Apakah Anda tahu bahwa Sdr. Budi akan menikah? |
| 5 | [Bentuk Biasa] のは KB です (yang ... adalah ...)<br> Kalimat (Bentuk Biasa)  +  のは  +  KB です | Pola penegasan: menonjolkan satu bagian informasi ("yang ... adalah ..."). Sering dipakai untuk MENGOREKSI ucapan lawan bicara. Subjek dalam anak kalimat sebelum の ditandai が, bukan は. | バンコクでうまれたんですか。……いいえ、うまれたのはチェンマイです。<br>Bankoku de umaretan desu ka. …iie, umareta no wa Chenmai desu<br>→ Lahir di Bangkok? ……Bukan, yang (tempat) lahir saya adalah Chiang Mai. |
