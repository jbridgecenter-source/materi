Tata Bahasa（ぶんぽう）

*Pola kalimat yang dipelajari di bab ini, beserta fungsi dan contoh.*

**Pola 1.  S（bentuk biasa）んです**

**Fungsi:** Memberi penjelasan/penekanan informasi.

**Pembentukan:** Kalimat bentuk biasa + んです

**Contoh:**

・この かばんは あねに もらったんです。

　*kono kabanha aneni morattandesu.*

　*→ Tas ini saya dapat dari kakak perempuan saya.*

**Pola 2.  A は B に C を あげます**

**Fungsi:** Menyatakan memberi: 'A memberi C kepada B'.

**Pembentukan:** A は B に C を あげます

**Contoh:**

・ジョイさんは アンディさんに 花を あげます。

　*joi sanha satousanni hana o agemasu.*

　*→ Joy memberi bunga kepada Andi-san.*

**Pola 3.  B は A に／から C を もらいます**

**Fungsi:** Menyatakan menerima: 'B menerima C dari A'.

**Pembentukan:** B は A に／から C を もらいます

**Contoh:**

・アンディさんは ジョイさんに／から 花を もらいます。

　*satousanha joi sanni / kara hana o moraimasu.*

　*→ Andi-san menerima bunga dari Joy.*

**Pola 4.  めいししゅうしょく② V（bentuk biasa）+ N**

**Fungsi:** Anak kalimat verba menerangkan nomina.

**Pembentukan:** Verba bentuk biasa + N

**Contoh:**

・あかちゃんが 着る もの

　*akachanga kiru mono*

　*→ barang yang dipakai bayi*
